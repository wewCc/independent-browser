# 使用与隐私说明

## 如何给任务

建议写明目标网页、允许执行的动作，以及最后要核对的结果。

- 查看 Notebook：「$independent_browser 在我的 Kaggle 作品中打开指定 Notebook，返回标题、草稿保存状态和会话状态，只查看。」
- 检查输入：「$independent_browser 在当前网页的搜索框填写“浏览器测试”，读取输入框的实际值，保留在当前页。」
- 下载文件：「$independent_browser 下载页面上的 results.csv，核对文件名和大小，给我本地链接。」

Codex 会从新鲜的页面快照定位元素，操作后核对页面状态。填写、提交以及启动计算是不同动作，应按实际授权执行。提交后若连接中断，应先查回执，再决定是否继续。

## 内部组件

| 组件 | 职责 |
|---|---|
| 用户技能 | 将直接调用路由到独立浏览器，约定同标签导航、登录交接和结果核验 |
| MCP 服务 | 本机 Node 启动固定版本的官方服务，桌面通过 STDIO 读取工具并发起调用 |
| Chrome | 使用专用 Profile 保存站点状态，提供快照、导航、表单、标签、截图及文件操作 |
| 诊断与测试 | 检查注册与握手，在独立的本地网页断言操作结果，并观察测试窗口状态 |

需要人工登录或验证码时，Codex 暂停网页操作，由使用者在独立窗口完成。保持最小化的任务优先同标签导航。浏览器进程关闭后需要重新查看页面；网页内的未保存编辑可能丢失。

## 本地数据

| 路径 | 用途 |
|---|---|
| `runtime/profiles/default/` | 日常自动化浏览器 Profile，包括站点登录状态 |
| `runtime/downloads/` | 浏览器下载暂存目录 |
| `runtime/screenshots/` | 默认截图以及 MCP 自动另存的下载成品 |
| `runtime/tests/` | 临时测试 Profile 和文件 |
| `config/playwright.local.json` | 此次安装生成的绝对路径配置 |
| `backups/`、`logs/`、`reports/` | 配置备份、维护记录和本机测试结果 |

这些位置均在项目忽略规则内。备份可能含其他服务的配置，截图和下载也可能含个人资料。分享测试结论时只摘录必要结果。

## 常见问题

- **技能可见，浏览器工具不可见。** 在本机执行环境运行 doctor，并核对桌面设置里的服务名。客户端重新加载后，用聊天实际读取一个页面。
- **浏览器工具可见，输入框却找不到。** 页面可能已跳转或重新渲染。重新获取快照，依据当前标题、控件名称和链接定位。
- **提示 Profile 已占用。** 等持有专用浏览器的会话结束。不要强删 Profile 锁或关闭所有 Chrome 进程。
- **配置或依赖缺失。** 从原安装目录运行 `./scripts/repair.ps1`，随后验证桌面调用。注册遇到手动编辑过的配置时，请先对照本地备份。
