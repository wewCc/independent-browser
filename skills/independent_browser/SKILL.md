# 独立浏览器

从当前工具目录发现 `mcp__independent_browser__*`。先用 `browser_tabs` 列出标签或用 `browser_snapshot` 查看当前页面。沿用专用 Profile，一次只由一个会话操作。不接管日常 Chrome，不使用物理鼠标键盘或桌面绝对坐标。

- 优先用最新快照中的链接、按钮和输入框引用。跳转或页面更新后重新读取。填写后读回实际输入值，打开目标后核对实际标题与地址，区分草稿状态、计算会话和已完成的实验结果。
- 用户要求后台或最小化时，保持当前窗口状态，优先在同一标签页导航。普通链接可先核对目标地址再原页打开。必须切换标签、打开新窗口或人工验证时，先暂停说明。报告最小化实测结果须有窗口状态证据。
- 用户手动登录或处理验证码时暂停，收到完成确认后再继续。仅返回任务需要的内容，省略认证查询参数；不采集或报告密码、Cookie、请求凭证。
- 遇到断开或元素失效，先检查服务、标签和页面状态。安全读取最多重试一次。提交、上传、发送、删除、付费或启动计算遵循用户授权；结果未知时先查回执或服务端状态，不重复执行。
- 服务未暴露时说明当前聊天的发现结果。按需检查桌面 MCP 设置和本项目的诊断脚本；不把其他浏览器或独立测试客户端的结果当成该服务的桌面调用。
